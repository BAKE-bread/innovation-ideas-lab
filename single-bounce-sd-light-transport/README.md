# Specular-Diffuse Plane Optical Simulation

这是一个基于蒙特卡洛光线追踪的物理模拟程序，用于计算一个特定场景下，接收器接收到的光通量。该场景由一个各向同性的点光源、一个理想漫反射（朗伯）平面和一个理想镜面反射平面构成。

程序能够分析在改变两个关键几何角度时，总光通量、漫反射光通量和镜面反射光通量的变化：
1.  **二面角 α (alpha)**: 镜面与水平漫反射面之间的夹角。
2.  **旋转角 θ (theta)**: 观测系统（光源和接收器）整体绕 X 轴的旋转角度。

## 功能特性

-   **物理精确性**: 基于渲染方程（Rendering Equation）进行光传输模拟。
-   **高级采样技术**:
    -   对漫反射组件使用**多重重要性采样 (MIS)**，有效降低复杂光路下的计算噪点。
    -   对镜面反射组件使用**镜像光源法**，实现无噪、高效的计算。
-   **稳健的几何处理**: 精确处理有限大小的反射平面及其相互遮挡关系。
-   **参数化**: 核心物理和几何参数（如反射率、功率、尺寸、角度）易于在代码中修改。
-   **可视化**: 使用 `matplotlib` 自动生成光通量随角度变化的曲线图。

## 直接运行
程序将开始计算，并在命令行显示进度条。计算完成后，会自动弹出两个绘图窗口，显示光通量随 `theta` 和 `alpha` 角度变化的曲线。

同样用户可以尝试调整重要的 `z1` 和 `z2` 参数，以收获完全不同的模拟结果。

## 模型描述与条件假设

为了使模拟可行，我们做出了以下关键的物理和几何假设：

1.  **光源**:
    * 是一个理想的**点光源**，没有物理体积。
    * 光照**各向同性**，即向所有方向均匀发光。
    * 总功率为 `P` (单位: W)。

2.  **反射表面**:
    * **漫反射面**:
        * 是一个理想的**朗伯体**，即从任何角度看亮度都相同。
        * 具有均匀的漫反射率 `rho_d`。
        * 几何上是一个位于 `z=0` 的有限矩形区域 `x∈[0,Lx], y∈[-Ly,Ly]`。
    * **镜面反射面**:
        * 是一个**理想镜面**，遵循完美的反射定律。
        * 具有均匀的镜面反射率 `rho_s`。
        * 几何上是一个有限的倾斜矩形，其在 x-y 平面上的投影为 `x∈[-Lx, 0], y∈[-Ly, Ly]`（根据代码 `is_on_finite_plane` 的逻辑推断）。

3.  **接收器**:
    * 是一个平坦的**圆形探测器**。
    * 是一个**完美吸收体**，它只测量到达其表面的光通量，不产生反射。

4.  **光线传播**:
    * 光线在真空中传播，不考虑空气等介质的吸收或散射。
    * **不考虑多次反射**。模拟只计算了两种路径的光：
        1.  `光源 -> 镜面 -> 接收器`
        2.  `光源 -> 漫反射面 -> 接收器`
        * 更复杂的光路，如 `光源 -> 漫反射面 -> 镜面 -> 接收器`，在此模型中被忽略。
    * 忽略光的波动性（如衍射、干涉）和偏振效应。所有计算均基于几何光学。

5.  **场景几何**:
    * 漫反射面和镜面反射面都经过坐标原点 `(0,0,0)`。
    * 二者的交线为 Y 轴。
    * 整个观测系统（光源和接收器）作为一个刚体绕 X 轴旋转。

## 代码结构

-   `sdplane-sim.py`:
    -   **参数定义**: 脚本开头定义了所有的物理和几何参数。
    -   **几何与辅助函数**:
        -   `get_geometry()`: 根据输入角度计算场景中各元素的位置和方向。
        -   `is_on_finite_plane()`: 判断一个点是否在有限的平面区域内。
        -   `is_path_occluded()`: 检测光路是否被另一个平面遮挡。
    -   **光通量计算函数**:
        -   `solve_specular()`: 计算镜面反射贡献。
        -   `solve_diffuse_mis()`: 计算漫反射贡献。
    -   **可视化驱动**:
        -   `visualize_results()`: 调用求解器，运行模拟并绘制结果图。
        -   `if __name__ == '__main__':`: 程序入口。
